El flujo de cálculo está conectado: valida entradas, muestra la fuerza y las cuatro comprobaciones, y anima las partículas. Las entradas inválidas muestran un aviso y borran el resultado anterior. La inversión de signo se presenta como “No aplica” para cargas cero.

## Dependencias locales

Bootstrap 5.3.9 y Anime.js 4.5.0 se incluyen en el repositorio. El HTML carga el bundle JavaScript de Bootstrap desde `Assets/Js/`.

## Guardado de simulaciones

- El simulador guarda los últimos 10 cálculos en memoria con `SaveSimulation`. Consulta [Historial de cálculos](/arquitectura#historial-de-cálculos).
- El repositorio ya no incluye `Api/Save_Simulation.php`, pero `App.js` sigue exportando `guardarSimulacionEnBackend`, que envía la petición a `api/save_simulation.php`. Ningún archivo usa esa función. Consulta [Guardar una simulación en un backend](/arquitectura#guardar-una-simulación-en-un-backend).
