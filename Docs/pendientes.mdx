El flujo de cálculo está conectado: valida entradas, muestra la fuerza y las cuatro comprobaciones, y anima las partículas. Las entradas inválidas muestran un aviso y borran el resultado anterior. La inversión de signo se presenta como “No aplica” para cargas cero.

## Dependencias locales

Bootstrap CSS 5.3.3 y Anime.js 3.2.2 se incluyen con sus licencias. No se necesita el bundle JavaScript de Bootstrap porque la interfaz no usa componentes interactivos de esa biblioteca.

## Guardado de simulaciones

- `Api/Save_Simulation.php` no tiene implementación.
- `guardarSimulacionEnBackend` envía la petición a `api/save_simulation.php`, en minúsculas. En servidores que distinguen mayúsculas, esa ruta no coincide con `Api/Save_Simulation.php`.
- Falta decidir entre el backend en PHP y un diccionario en JavaScript con los últimos 10 cálculos. Consulta [Guardar una simulación](/arquitectura#guardar-una-simulación).
