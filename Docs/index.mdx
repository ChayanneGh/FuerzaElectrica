El Simulador de Fuerza Eléctrica es una aplicación web que calcula la fuerza entre dos cargas puntuales a partir de sus valores y de la distancia que las separa. Usa HTML, Bootstrap 5, Anime.js y JavaScript, y hace todo el cálculo en el navegador.

<Info>
  El motor y la interfaz están conectados. El guardado de simulaciones sigue
  pendiente. Consulta [Pendientes](/pendientes) para ver qué falta.
</Info>

## Qué hace

- Recibe la carga 1 y la carga 2 (en coulombs) y la distancia entre ellas (en metros).
- Calcula la magnitud de la fuerza con `F = k·|q1·q2| / r²`.
- Indica si la fuerza es de atracción o de repulsión, y anima las partículas según el tipo de interacción.
- Muestra el resultado en notación decimal o científica, según su tamaño.
- Ejecuta cuatro comprobaciones físicas sobre el resultado: distancia doble, carga doble, signo invertido y acción y reacción.

## Ejecutar el simulador

1. Clona el repositorio.
2. Las librerías necesarias están incluidas en el repositorio.
3. Sirve la carpeta del proyecto con un servidor local y abre `Index.html` en el navegador.

<Note>
  Los archivos de JavaScript usan `import` y `export`. El navegador solo los
  carga como módulos cuando la página se sirve desde un servidor, no al abrir
  `Index.html` directamente como archivo.
</Note>
