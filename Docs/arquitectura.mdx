## Estructura del proyecto


## Componentes

### Capa de presentación

`Index.html` usa la grilla de Bootstrap para dividir la página en dos columnas:

- **Controles de simulación (izquierda):** inputs `#carga1` y `#carga2` (en coulombs), `#distancia` (en metros, mínimo `0.0001`) y el botón `#btnSimular` (**Calcular Fuerza**). Los valores iniciales son `0.000002`, `-0.000003` y `0.5`.
- **Área de visualización (derecha):** dos partículas, `#particula1` (q₁) y `#particula2` (q₂), y el texto `#txtTipoInteraccion`.
- **Resultados principales:** `#forceResult` muestra la fuerza con formato y `#txtTipo` muestra el tipo de interacción.
- **Comprobaciones físicas:** cuatro indicadores, `#chkCuartaParte`, `#chkDobleCarga`, `#chkInvertirSigno` y `#chkAccionReaccion`, que empiezan en **Pendiente**.

La página carga `UI.js` como módulo (`type="module"`), además de `anime.min.js` y el bundle de Bootstrap.

### Capa de lógica

- **`Physics.js`:** exporta la clase [`CoulombPhysics`](/calculo-fuerza). No accede al DOM. Calcula la fuerza base y los cuatro escenarios de [comprobación](/calculo-fuerza#comprobaciones) al crear la instancia.
- **`UI.js`:** al pulsar `#btnSimular`, lee los inputs, crea una instancia de `CoulombPhysics`, escribe el resultado y el tipo en la página, actualiza `#chkCuartaParte` y anima las partículas con Anime.js.
- **`App.js`:** exporta la función asíncrona [`guardarSimulacionEnBackend`](#guardar-una-simulación), que envía una simulación al backend.

### Animación de las partículas

`UI.js` mueve las partículas según el `Tipo` de la fuerza base:

| Tipo | Movimiento |
| --- | --- |
| `"Repulsion."` | q₁ se desplaza 30 px a la izquierda y q₂ 30 px a la derecha, y vuelven. |
| `"Atraccion."` | q₁ se desplaza 20 px a la derecha y q₂ 20 px a la izquierda, y vuelven. |
| `"Nula."` | Sin animación. |

Cada animación dura 600 ms y se repite dos veces en modo `alternate`.

## Guardar una simulación

`App.js` exporta `guardarSimulacionEnBackend(carga1, carga2, distancia)`. La función crea una instancia de `CoulombPhysics` y envía con `fetch` una petición `POST` a `api/save_simulation.php`, con este cuerpo JSON:

```json
{
  "fuerzaBase": { "Magnitud": 0.2157, "Tipo": "Atraccion.", "Formato": "0.2157 N." },
  "comprobaciones": {
    "cuartaParte": true,
    "dobleCarga": true,
    "invertirSigno": true,
    "accionReaccion": true
  }
}
```

La función devuelve la respuesta del servidor convertida con `response.json()`. Si la petición falla, escribe el error en la consola y lo vuelve a lanzar.

<Warning>
  El backend todavía no existe. `Api/Save_Simulation.php` solo contiene un comentario, y `UI.js` aún no llama a `guardarSimulacionEnBackend`. El equipo está evaluando reemplazar el backend por un diccionario en JavaScript que guarde como máximo los últimos 10 cálculos (datos de entrada y resultado) y se borre al recargar la página.
</Warning>

## Flujo de datos

```text
[ El usuario ingresa cargas y distancia ]
                 │
                 ▼
 [ UI.js captura los valores al pulsar Calcular Fuerza ]
                 │
                 ▼
[ new CoulombPhysics(q1, q2, r) calcula la fuerza y las comprobaciones ]
                 │
                 ▼
[ UI.js muestra el resultado, las comprobaciones y anima las partículas ]
                 │
                 ▼
[ (Planeado) App.js envía la simulación al backend ]
```
